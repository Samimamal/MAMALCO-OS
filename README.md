# MAMAL Central + mamalco.com

یک سیستم با دو بخش:
- **سایت عمومی (mamalco.com):** هر سازه‌ی مامال صفحه‌ی خودش را دارد: موقعیت GPS روی نقشه، عکس‌ها، محصولات و سفارش آنلاین، و فرم‌های سرمایه‌گذاری، اجاره و استخدام.
- **پنل مدیریت (`/admin`):** هر سازه یک کسب‌وکار مستقل است با فروش، هزینه، حسابداری، کارکنان، سرمایه‌گذاران و درخواست‌های خودش.

برای شروع ۹۰ سازه تعریف می‌شود: ۳۰ سازه‌ی فرم‌دار شهری (`F-01`…`F-30`)، ۳۰ سازه‌ی دهکده (`V-01`…) و ۳۰ اقامتگاه (`L-01`…).
هر سازه فقط وقتی روی سایت دیده می‌شود که «انتشار» روشن باشد و موقعیت GPS و دست‌کم یک عکس داشته باشد.

### گزارش روزانه چه چیزی را ثبت می‌کند
- فروش نقدی، کارت با POS مامال، و **کارت با POS همسایه یا حساب شخصی** (جداگانه، چون این پول به حساب مامال نمی‌رسد)
- تعداد مشتری (میانگین فاکتور خودکار حساب می‌شود)، خرید جنس، ضایعات، توضیحات
- عکس فاکتورها و رسید POS (jpg / png / webp / heic / pdf، حداکثر ۱۰ مگابایت)

داشبورد این موارد را علامت می‌زند: روز بدون گزارش، گزارش بدون عکس، فروش خارج از POS مامال، و درصد رسیدن به هدف روزانه.

### قرارداد مشارکت و صورت‌حساب سرمایه‌گذار
پیش‌فرض‌ها از الگوی قرارداد «اتوبوس کافه مامال ۰۳» است: مدت ۳ سال (تا ۵ سال قابل تمدید)، سهم ۶۰/۴۰ (سرمایه‌گذار/مدیر) تا برگشت سرمایه و ۳۰/۷۰ بعد از آن، حق مدیریت ۱۰٪ فروش قبل از تقسیم، جریمه‌ی خروج ۷/۵/۳٪، و ارزش خروج = میانگین سود خالص ۶ ماه × ۲ × سهم سرمایه‌گذار.

برای هر ماه شمسی:
سود خالص = فروش (گزارش روزانه) − خرید مواد (گزارش روزانه) − هزینه‌های ماهانه − حق مدیریت.
ماهی که سرمایه در آن برمی‌گردد به‌صورت نسبی تقسیم می‌شود. صفحه‌ی قرارداد درصد برگشت سرمایه، پیش‌بینی ماه‌های باقی‌مانده، جریمه و ارزش خروج امروز را نشان می‌دهد.
فرض‌ها: زیان یک ماه به ماه بعد منتقل نمی‌شود؛ جریمه‌ی خروج درصدی از سرمایه‌ی برنگشته است.
کد ملی و مدارک هویتی سرمایه‌گذار در سیستم ذخیره نمی‌شود؛ فقط لینک پوشه‌ی محدود Drive.

### کاتالوگ سازه‌ها (تومان، تا بهره‌برداری)
| نوع | بازه |
|---|---|
| سازه‌های فرم‌دار (کیوسک، کافه، اتوبوس‌کافه، چای‌خانه) | ۱٫۵ تا ۳ میلیارد |
| سازه‌های دهکده | ۳ تا ۶ میلیارد |
| اقامتگاه‌های مامال | ۶ تا ۱۰ میلیارد |

ادمین قیمت‌ها را در صفحه‌ی `/catalog` به‌روز می‌کند؛ قیمتی که بیش از ۷ روز به‌روز نشده قرمز می‌شود.

### قوانین کسب‌وکار (`mamal_central/rules.py`)
- سرمایه‌گذاری سازه‌ی فرم‌دار: حداقل ۷۰۰ میلیون نقد، باقی با چک؛ ساخت ۴۵ روز، ۵۰٪ در شروع و ۵۰٪ تا تکمیل.
- دهکده و اقامتگاه: ۵۰٪ نقد (نصف حداقل قیمت کاتالوگ)، باقی مرحله‌ای؛ پیش‌ثبت‌نام تا بهار.
- حقوق: ۱۵ تا ۳۰ میلیون؛ افزایش «۳ میلیون هر ۶ ماه» یا «۵ میلیون هر سال» (برای هر کارمند انتخاب می‌شود)؛ قرارداد حداقل ۱۲ ماه.
- فرم‌های عمومی کد ملی، شماره حساب یا مدارک نمی‌گیرند؛ صفحه‌ی سرمایه‌گذاری سود تضمینی وعده نمی‌دهد.

### نقش‌ها
- **ادمین (admin):** همه‌ی فضاهای کاری
- **مدیر (manager):** داشبورد، گزارش‌ها، هزینه‌ها و قراردادهای فضای کاری خودش (فقط ادمین قرارداد ثبت یا ویرایش می‌کند)
- **اپراتور (staff):** فقط فرم گزارش؛ ثبت یا اصلاح فقط برای امروز و دیروز
- دسترسی هر کاربر را می‌توان به **یک سازه** محدود کرد: `grant mehran mamal-form staff --unit F-01`

## اجرا

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# ۹۰ سازه (F-01..F-03 = MAMAL Bazaar، چای‌خانه، لبنیات) + کاتالوگ قیمت
.venv/bin/python -m mamal_central.cli init-structures
.venv/bin/python -m mamal_central.cli init-catalog
.venv/bin/python -m mamal_central.cli create-user sami --full-name "سامی مامال" --admin

# اپراتور MAMAL Bazaar
.venv/bin/python -m mamal_central.cli create-user mehran --full-name "مهران"
.venv/bin/python -m mamal_central.cli grant mehran mamal-form staff --unit F-01

.venv/bin/uvicorn --factory mamal_central.main:app_factory --host 0.0.0.0 --port 8000
```

دستورهای دیگر: `add-workspace`، `add-unit`، `set-password`، `list`.

### نقشه و زمین‌ها
```bash
# زمین دهکده (قلاتوک، ۱۳٬۵۰۰ m²) از روی جدول UTM کروکی
.venv/bin/python -m mamal_central.cli init-village-site
# پلیگون اقامتگاه از گوگل‌ارث: Save Place As… → .kml
.venv/bin/python -m mamal_central.cli import-kml lodge1.kml --code SITE-LODGE-01 --category lodge --declared-area 2000
# نقاط پیشنهادی شهرداری: CSV با ستون‌های code,x,y (UTM زون ۳۸) یا code,lat,lng
.venv/bin/python -m mamal_central.cli import-points points.csv
```
کروکی زمین دهکده فقط ۷ رأس دارد؛ ضلع p1→p2 در امتداد راه دسترسی قوسی است، برای همین مساحت چندضلعی ساده (~۱۷٬۸۵۰ m²) از مساحت اعلامی (۱۳٬۵۰۰ m²) بیشتر است. برای مرز دقیق، نقاط میانی را از نقشه‌بردار بگیرید.

### تنظیمات (متغیرهای محیطی)
| متغیر | پیش‌فرض |
|---|---|
| `MAMAL_DATA_DIR` | `./data` (دیتابیس، عکس‌ها، کلید session) |
| `MAMAL_DATABASE_URL` | SQLite داخل `MAMAL_DATA_DIR` |
| `MAMAL_SECRET_KEY` | به‌صورت خودکار ساخته و در `data/secret_key` نگه داشته می‌شود |

روی سرور (IONOS) پشت nginx با HTTPS اجرا شود (uvicorn با `--proxy-headers`) و از پوشه‌ی `data/` روزانه بکاپ گرفته شود.
هنوز ابزار migration نداریم؛ چون دیتابیس واقعی هنوز ساخته نشده مشکلی نیست، ولی قبل از اولین داده‌ی واقعی Alembic اضافه می‌شود.
سایت آلمانی MAMALCO GmbH طبق قانون آلمان صفحه‌ی Impressum و Datenschutz لازم دارد؛ متن آن باید با مشاور حقوقی نهایی شود.
